Which protocol is worth farming next?

Ranking the protocols that record no token yet

Every protocol with at least $50M of TVL and no token on record, plus every smaller pre-token protocol the snapshot carries — ranked by what a launch would be worth if the protocol's record stayed as it is. Implied value is this radar's own estimate, never a price and never a promise that a token comes.

How implied value is computed

One function scores every protocol. No name is special-cased and no row is hand-picked. The peer ratio is the heart of it: launched tokens do not all trade at one multiple of TVL, so each category is priced at what its own launched tokens actually fetch.

1 · Peer calibration

For each category, take the median market-cap-to-TVL ratio of its launched tokens, then shrink it toward the global median (4 parts global) so a category with one or two launched tokens cannot set an absurd price. Clamped to 0.02 – 2.5. A category with no launched peer prices at the global median.

2 · Growth

Seven-day TVL change, clamped to −50%…+150%, moves the value by half its size: a protocol growing 20% in a week is worth 10% more than one standing still, and one shrinking 20% is worth 10% less.

3 · Maturity & reach

Age since first listing, up to 3 years, lifts the value by up to 30% — a protocol that has run for years with no token has had longer to build the habit a launch rewards. Each extra chain beyond the first adds 2%, up to 10%.

4 · Confidence

A data-completeness score out of 100. It falls when the 7-day change or the listing date is missing, and when the category has few launched peers to calibrate against. It says how much the snapshot supports the number — not whether a token launches.
